## Method

Everything here is read as data; no method bodies, clause bodies, comments or source text are copied.

- **Exports:** the PE export directory (names, ordinals, forwarders) is parsed directly, using
  `System.Reflection.PortableExecutable` for headers and sections. MSVC-decorated names are undecorated with
  dbghelp `UnDecorateSymbolName` (`UNDNAME_COMPLETE` for the signature, `UNDNAME_NAME_ONLY` for the class).
- **Lisp:** an S-expression reader that skips strings and comments records depth-0 definition forms with their
  required-parameter counts and lambda-list keywords.
- **Prolog:** Mathcad's Prolog files use Lisp syntax; the same reader records clause heads as name/arity.
- **Axiom:** package names come from the `*.NRLIB` directory names; constructor, abbreviation and operation
  signatures come from the Lisp data in each `index.KAF`.
- **MCADINCL.H:** a small C tokenizer records prototypes, struct fields, typedefs and `#define` names
  (values only when they are plain numeric literals).
