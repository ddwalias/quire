# Mirror coverage

Generated by `MirrorGen manifest` from the current build. Each member of a mirrored type has one status
(PLAN.md §3c), from its attributes:

- **Stub** `[MirrorStub]`: generated, throws.
- **Unclassified** (no attribute): hand-written before §3c; still to be analyzed with REA, or marked Quire-only.
- **Blocked** `[MirrorBlocked(reason)]`: REA couldn't expose or settle the original; throws, reason recorded.
- **Documented** `[MirrorDocumented(source)]`: documentation-only; not sufficient for completion.
- **Analyzed** `[MirrorAnalyzed(evidence)]`: REA analysis recorded in [`evidence/`](evidence/); no passing behaviour test yet.
- **Tested** `[MirrorTested(evidence)]`: REA-analyzed, implemented independently, behaviour tests pass.
- **Verified** `[MirrorVerified(test)]`: differential-verified against the installed Mathcad, for the recorded cases only.
- **Deviation** `[MirrorDeviation(id)]`: an accepted entry in [`deviations.md`](deviations.md); a divergence, never a match.
- **Quire-only** `[QuireOnly]`: no Mathcad counterpart.

*Settled* is Tested + Verified + Deviation + Quire-only (§3c rule 7). Blocked, documented and analyzed members
are open. Settled says nothing about untested inputs, and deviations are counted apart from matches.
Explicit interface implementations, enum values and delegate signatures are not counted. Per-member detail is
in [`status/`](status/).
